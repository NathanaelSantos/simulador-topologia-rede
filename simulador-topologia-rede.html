O envio segue o fluxo real: mesma rede → ARP/entrega direta; outra rede → gateway → rota → entrega. Qualquer falha interrompe com a causa exata.

🎯 Teste de invasão (didático)

O aluno cria um arquivo secreto no host. Se o “invasor” (professor) conseguir ler esse arquivo, a rede falhou — esse é o gancho para falar de firewall.

Regra do lab: firewall do host desligado → invasão obtém o arquivo (vermelho / falha). Firewall ligado → ataque bloqueado (verde / rede resiste). Não é um ataque real — só simulação de aula.
